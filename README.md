# Mini_Pad

# Discription

This custom buit micropad is powered by a Seeed Studio XIAO RP2040 and runs QMK firmware to function as a dedicated video and photo editing controller.
It has 4 mechanical switchers and a rotary encoder including 0.91 oled display. They are programmed to do various tasks like tool selection, layer toggling and intutive timeline scrubbing.
Oled display is used to show the active layer and current keybinds while LED attached changes color as per different operational modes selected.
